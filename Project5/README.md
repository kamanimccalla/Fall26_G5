# Project 5 — Study Habit Tracker Mobile App

This folder contains Kamani Mccalla's Project 5 contribution: a React Native Expo implementation of the **Create and Track Study Goals** feature.

## Contents

- `ai_prompt.md` — five-section AI prompt required by the assignment
- `minutes_1.md`, `minutes_2.md`, and `minutes_3.md` — individual meeting records
- `app/` — Expo Router mobile application

## Run the Application

1. Install Node.js LTS.
2. Open a terminal inside the `Project5/app` folder.
3. Run `npm install`.
4. Run `npx expo start`.
5. Open the project in Expo Go, an Android emulator, an iOS simulator, or the web preview.

## Working Interactions

- **Create Goal** opens the goal form.
- **View Goal Progress** opens the progress screen.
- **Save Goal** validates and displays the entered goal.
- **Log Study Session** displays a prototype message.
- **Return Home** returns to the Home screen.
